# Password Generator & Strength Checker

A Python-based password generator and password strength checker.

## About the Project

This project combines two useful password security features in one program. It can generate random passwords and check the strength of a password entered by the user.

I created this project to practice Python programming and learn some basic concepts related to password security.

## Features

- Generate random passwords
- Choose password length
- Use uppercase and lowercase letters
- Include numbers and special characters
- Check password strength
- Basic input validation
- Simple command-line interface

## Technologies Used

- Python 3
- Secrets module
- String module
